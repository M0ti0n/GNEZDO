# Relief SingleLine (single-stroke font)

Used by GNEZDO to engrave text with single strokes (traced lines, no outline to fill): `src/import/singleLine.ts`.

- Source: https://github.com/isdat-type/Relief-SingleLine (`fonts/open_svg/ReliefSingleLineSVG-Regular.svg`)
- Copyright 2021–2022 The Relief SingleLine Project Authors
- License: SIL Open Font License 1.1, see `OFL.txt` (this folder). The conversion below is a Modified Version of the Font Software and is under the same license.

`glyphs.json` holds the glyphs of Basic Latin, Latin-1 and Latin Extended-A (plus a few punctuation marks) taken from the SVG font: for each character its advance width and its open paths (SVG path data, 1000 units per em, y up). Nothing else was changed.
