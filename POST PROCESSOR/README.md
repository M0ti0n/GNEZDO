# POST PROCESSOR

One zip per machine: its postprocessor and technology tables. Import in GNEZDO: Settings → Machines → Import machine.

| Zip | Machine |
|---|---|
| `HACO-KOMPAKT-plasma.gnezdo-machine.zip` | HACO KOMPAKT plasma, ISO incremental, 80 A and 130 A technology tables |
| `LVD-AXEL-laser.gnezdo-machine.zip` | LVD Axel 3015 laser (.CNC: a subprogram per part, G980 placement, E codes), MS (MS, Mn12, HARDOX) and SS (SS, ALU, Zn) technology tables. 0,0 corner set to bottom left: check it on the machine |

Each zip's files also sit loose in a folder of the same name, to read and diff.
