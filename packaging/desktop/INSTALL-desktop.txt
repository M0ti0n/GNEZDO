GNEZDO - DESKTOP VERSION
========================

One person, one PC. No server, no database to set up, no sign-in.

Everything GNEZDO keeps (parts, jobs, settings, the diagnostic log) is in your own
app-data folder, not in the GNEZDO folder, so updating or deleting the GNEZDO folder
does not touch it:
    Windows:  %LOCALAPPDATA%\GNEZDO     (e.g. C:\Users\you\AppData\Local\GNEZDO)
    Linux:    ~/.local/share/gnezdo
GNEZDO menu -> Settings -> Data shows it, opens the folder, and makes a backup.


1. WINDOWS
----------
Unzip gnezdo-desktop-windows.zip somewhere you can write to, e.g. Documents
(not "Program Files"). Open the GNEZDO folder and double-click GNEZDO.exe.
GNEZDO opens in its own Edge window (Edge comes with Windows 10 and 11).

The first time Windows may say "Windows protected your PC": click "More info",
then "Run anyway" (the program is not signed).

A shortcut: right-click GNEZDO.exe -> Send to -> Desktop (create shortcut), or
right-click it -> Pin to Start / Pin to taskbar.


2. LINUX
--------
Needs: Chromium, Google Chrome, Microsoft Edge or Brave (any one; without one GNEZDO
opens in the default browser). Everything else is in the folder.

    tar xzf gnezdo-desktop-linux.tar.gz -C ~/
    ~/gnezdo/install-menu-entry.sh      # GNEZDO in the applications menu and on the desktop
    ~/gnezdo/gnezdo                     # or start it from a terminal

Or in the file manager: open the gnezdo folder, right-click install-menu-entry.sh ->
"Run as a Program" (or double-click it and choose Run); then start GNEZDO from the
applications menu or the desktop icon. GNEZDO opens in a window of its own (Chromium /
Chrome / Edge / Brave), or as a tab in the default browser when none of those is installed.
If nothing opens, see logs in ~/.local/share/gnezdo.

Built for 64-bit PCs (x86-64) with Ubuntu 22.04 or newer, Debian 12, Fedora 36 or newer,
or similar.


3. USING IT
-----------
- Closing the GNEZDO window: when a job has unsaved changes or a nest is running,
  GNEZDO asks first. GNEZDO itself stops 30 seconds after its window is closed. Start
  it again within that time and it carries on where it was.
- Starting GNEZDO when it already runs opens another window to it.
- Saves and the diagnostic log carry the PC's user name.
- GNEZDO can only be reached from this PC (it is not on the network). For several
  people sharing parts and jobs, use the server version.


4. UPDATING
-----------
Close GNEZDO, then replace the GNEZDO folder with the new one (keep config.json, if
you made one). The data is brought up to date at the next start.

Backup: Settings -> Data -> "Back up now" saves a copy of the database (one file,
gnezdo-backup-....db) to your Downloads. To go back to a backup: close GNEZDO and
replace data\gnezdo.db in the app-data folder with it (renamed to gnezdo.db).
To move GNEZDO to another PC: install it there and do the same with a backup.


5. SETTINGS (optional)
----------------------
A config.json in the GNEZDO folder (next to GNEZDO.exe / gnezdo) can change:

    {
      "Gnezdo": {
        "DesktopPort": 8096,
        "Browser": "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe"
      }
    }

DesktopPort: when another program uses port 8095. Browser: a different browser.
DesktopRoot: keep the data in another folder (e.g. "D:\\GNEZDO-data").

DWG DRAWINGS: GNEZDO reads DXF and SVG itself; a DWG is converted to DXF on the
PC GNEZDO runs on, by one of these (GNEZDO finds it by itself):
- ODA File Converter (free, from opendesign.com: "ODA File Converter"); install
  it in its usual folder (C:\Program Files\ODA\...).
- LibreDWG's dwg2dxf.exe, put in a folder "tools" next to "program".
Or set its full path as "Gnezdo": { "DwgConverter": "..." } in config.json.
Without one, a DWG in the import list says so: save it as DXF in your CAD.
